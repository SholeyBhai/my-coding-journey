## Practice

Today I practiced `do-while`, `break`, and `continue` using Java loops.

### do-while
A do-while loop executes the code first and checks the condition afterward.

### break
The break statement completely stops the loop when a condition is met.

### continue
The continue statement skips the current iteration and continues with the next iteration.

## Break vs Continue

- `break` → stops the loop completely
- `continue` → skips the current iteration
